■ 2. 権限（ロール）について
--------------------------------------------------------------------------------
本アプリには3種類の権限（ロール）があり、見れる画面や操作できる範囲が制御されます。

  👑 【システム管理者】 (system_admin)
      ・全データ（10,096銘柄・7,550製品）の閲覧、編集、削除、一括CSVインポート、AI機能を含む全権限。
      ・システム管理画面 (/admin.html) および 酒蔵ポータル (/brewery_admin.html) へアクセス可能。

  🍶 【酒蔵管理者】 (brewery_admin)
      ・自社の酒蔵基本プロフィールの編集、自社銘柄の追加・修正・削除、および自社ファンの口コミ・評価分析。
      ・酒蔵専用ポータル (/brewery_admin.html) にアクセス可能（他社データは編集不可）。

  👤 【一般利用者】 (user)
      ・日本酒の検索・閲覧・詳細確認、全国酒蔵マップの閲覧、および自身の名前での口コミ投稿・修正・削除。
      ・管理画面へのアクセスは制限されます。
